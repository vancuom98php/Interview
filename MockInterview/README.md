# 🗣️ Mock Interview

Thư mục lưu **các cuộc phỏng vấn thử** đã thực hiện (transcript + đánh giá).

- Mỗi buổi → một file `.md` đặt tên `YYYY-MM-DD-<vi-tri>.md`
  (vd `2026-07-17-backend-nodejs.md`).
- Nội dung được sinh bởi skill [`mock-interview`](../.claude/skills/mock-interview/SKILL.md):
  Claude đóng vai **nhà tuyển dụng**, hỏi **từng câu một** dựa trên CV/JD/ảnh + vị trí/level;
  bạn trả lời như ứng viên. Kết thúc → tổng kết (điểm mạnh/yếu, câu trả lời mẫu, chấm điểm theo
  mảng, kết luận Pass/Cân nhắc/Chưa đạt) và lưu toàn bộ transcript vào đây.

## Cách bắt đầu

Cung cấp cho Claude: **vị trí & level**, **CV**, và **JD/ảnh** nếu có, ví dụ:

> "Phỏng vấn thử vị trí Backend Node.js (Middle). CV của mình ở `cv.pdf`, JD dán bên dưới..."

Gõ **"kết thúc"** bất cứ lúc nào để dừng và nhận đánh giá.

_(Chưa có buổi nào — file sẽ xuất hiện sau buổi phỏng vấn thử đầu tiên.)_
