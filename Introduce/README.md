# 🙋 Introduce

Thư mục lưu phần **giới thiệu bản thân & câu hỏi behavioral/HR** (viết bằng **tiếng Anh**).

- File nội dung: `introduce.md` — "tell me about yourself", điểm mạnh/yếu, câu hỏi tình huống,
  câu hỏi HR. Định dạng 2 phần theo [`/CLAUDE.md`](../CLAUDE.md) §4 (📖 Background + 🎯 Interview answer).
- Nội dung được sinh bởi skill [`interview-answer`](../.claude/skills/interview-answer/SKILL.md)
  khi bạn dán một câu hỏi giới thiệu/behavioral.

## ⚠️ Riêng tư

`introduce.md` chứa thông tin **cá nhân** (kinh nghiệm, câu chuyện thật, mục tiêu nghề nghiệp)
nên đã được liệt kê trong [`.gitignore`](../.gitignore) — **không** đẩy lên GitHub.
Chỉ file `README.md` này được commit để thư mục vẫn tồn tại trên repo.
